# Live 2D pose implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Real MediaPipe Lite skeletons on Capture tiles at ~10 fps while the pose toggle is on.

**Architecture:** A live-pose heartbeat (same shape as standing mode) tells phones to send 320 px previews every 100 ms. Each tile long-polls its newest frame and runs a shared Lite landmarker on it.

**Tech Stack:** React 19, TypeScript, Node HTTP backend, `@mediapipe/tasks-vision`, Vitest.

## Global Constraints

- Preview intervals: standing 66 ms, live pose 100 ms, idle 400 ms. Live pose keeps 320 px and JPEG 0.55.
- Heartbeat expiry 6 s; Capture beats every 2 s.
- Tag copy: `2D pose · loading`, `2D pose · live`, `2D pose · no person`, `2D pose · unavailable`.
- No placeholder skeleton. Overlay never saved.
